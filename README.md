# 🎮 מסע ה-VLAN — VLAN Quest

משחק לימודי תלת־ממדי (דפדפן) שמלמד תלמידים **מה זה VLAN, למה צריך אותו, איך הוא עובד, איך זה נראה בלי ועם, אילו מכשירים עובדים איתו, מה היה לפניו, מה היתרונות והחסרונות, איך מגדירים אותו ב-Cisco ואיך בודקים שהוא באמת עובד**.

בכל תחנה: **שיעור־סימולציה תלת־ממדי אינטראקטיבי** שמסביר בפועל מה קורה ברשת (לא "רובוט מדבר") ← ואחריו **מיני־משחק** ב-3 רמות ← מדליות, כוכבים וניקוד. בסוף: **מבחן סיום מול "מפלצת ה-Broadcast"**, **תעודת הבנה** להורדה/הדפסה וגביע האלוף 👑.

## ▶️ איך מריצים

אין שלב בנייה ואין תלות ברשת (ספריית Three.js מצורפת ב-`lib/`).

* **הכי פשוט:** לפתוח את `index.html` בדפדפן (Chrome / Edge / Firefox).
* **או שרת מקומי:** `npx http-server .` (או `python3 -m http.server`) ואז לפתוח `http://localhost:8080`.
* **אירוח:** אפשר להעלות כמו שהוא ל-GitHub Pages / כל אחסון סטטי.

מומלץ עם צליל. עובד עם עכבר, מקלדת ומסך מגע (כולל טלפון).

פרמטרים שימושיים במחרוזת הכתובת: `?unlock=1` פותח את כל התחנות (למורים / לבדיקה), `?debug=1`.

### 🎚️ רמות (מתאים גם למי שלא גיימר)

* 🥉 **מתחילים** (x1) – רגוע, עם עזרה והנחיות, אין "מוות". אין "מוות". **כל רמה שמסיימים מקדמת בתחנה** (לא חייבים דווקא את "מתחילים"): גיימר יכול לעבור ישר ל"אגדות", ומי שלא גיימר מסיים "מתחילים" וממשיך.
* 🥈 **מתקדמים** (x1.6) – מהיר יותר, פחות רמזים.
* 🥇 **אגדות** (x2.5) – אתגר אמיתי לגיימרים: לחץ זמן, חיים, כללים משתנים.

בכל רמה 1–3 כוכבים לפי הניקוד. מדליה (ארד/כסף/זהב) לכל רמה, גביעים כשמשלימים רמה בכל 9 התחנות, ו-19 הישגים.

### 🤝 להשוות עם חברים (בלי שרת)

בכפתור **📊 מובילים** יש "קוד" אישי (וקישור). שולחים אותו לחבר; החבר מדביק אותו אצלו – ומקבלים טבלת דירוג והשוואה תחנה־מול־תחנה. הכול נשמר מקומית בדפדפן (`localStorage`).

## 🧪 הסימולטור של Cisco

`js/cli.js` הוא סימולטור IOS אמיתי (לא "מחרוזות מוכנות"):

* מצבים: user / privileged / global config / interface / interface range / vlan / sub-interface / SVI.
* קיצורי פקודות (`conf t`, `int fa0/1`, `sw mo tr`, `sh vlan br`), `?`, Tab, היסטוריה (↑↓), `do`, סינון `| include | begin | section`, שגיאות עם סמן `^` ("Invalid input", "Incomplete", "Ambiguous").
* מודל התקן: VLAN database, Access/Trunk/Dynamic (DTP), Native, Allowed (`add/remove/except/none/all`), Voice VLAN, shutdown, SVI, `ip routing`, Router-on-a-Stick, שמירה ל-startup-config.
* **מנוע הגעה (reachability)** שמחשב אם ping באמת עובד לפי ההגדרות: פורט → VLAN → Trunk (Allowed/Native) → Gateway → ניתוב. אותו מנוע מפעיל את ה-`show`, ה-ping מהמחשבים והמודל התלת־ממדי (`Lab3D`).
* פקודות show: `vlan [brief|id|name]`, `interfaces trunk`, `interfaces status`, `interfaces X switchport`, `ip interface brief`, `ip route`, `mac address-table`, `running-config [interface X]`, `startup-config`, `cdp neighbors`, `version`.
